Privacy

This site sets no cookies, stores nothing in your browser and runs no analytics. Every file a page loads comes from this domain, so nothing is requested from a third party while you read — which is why there is no banner to dismiss.

It is hosted on GitHub Pages. GitHub logs the visitor's IP address for security, on its own infrastructure and under its own terms; I never see those logs. GitHub's privacy statement covers them.

There is no database here, and no list. The only thing I ever hold is a message you chose to send me: if you email me it sits in my inbox, I use it to reply and for nothing else, and it goes to no one.
